# Spreadsheet

C++-проект для работы с электронными таблицами, формулами, зависимостями и вычислением выражений

Этот проект — реализация мини-электронной таблицы: системы, которая хранит ячейки с текстом и формулами, вычисляет значения, отслеживает зависимости, предотвращает циклы, а также эффективно пересчитывает связанные ячейки благодаря кешированию.

---

# Возможности проекта

## 1. Работа с таблицей

Поддерживается:

* хранение ячеек по адресам (формат A1, C5 и т. д.)
* автоматическое создание ячеек при обращении к ним
* очистка ячеек
* вычисление видимой части таблицы (размер печати)

Текстовые ячейки поддерживают:

* любой текст
* экранирование при помощи символа `'` для строк, начинающихся с `=`

## 2. Формулы

Проект реализует мини-язык формул с поддержкой:

* бинарных операций `+` `-` `*` `/`
* унарных `+` `-`
* скобок
* ссылок на другие ячейки: `A1 + B2 * C3`
* автоматического форматирования выражений (удаление лишних пробелов и скобок)

Работа формул основана на:

* ANTLR4-грамматике (Formula.g4)
* построении AST (абстрактного синтаксического дерева)
* рекурсивном вычислении выражений
* детальной обработке ошибок (`#REF!`, `#VALUE!`, `#ARITHM!`)

## 3. Отслеживание зависимостей

Каждая формула знает, на какие ячейки она ссылается.
Каждая ячейка знает, кто зависит от неё.

Поддерживается:

* автоматическое обновление зависимостей при изменении формулы
* корректное удаление зависимостей старой формулы
* учёт пустых ячеек и ссылок за границами таблицы

## 4. Обнаружение циклов

Если новая формула создаёт цикл (например, A1 зависит от B1, а B1 от A1), то выбрасывается исключение `CircularDependencyException` 

Проверка выполняется через обход графа зависимостей (BFS).

## 5. Производительность: кеширование значений

Значения формул сохраняются в кеше (`mutable std::optional<Value>`).
Кеш инвалицируется только у тех ячеек, зависимых от измененной.

Позволяет:

* избегать повторных вычислений
* мгновенно печатать большие таблицы
* минимизировать пересчёт при локальных изменениях

# Архитектура проекта

```
┎── main.cpp                  — запуск тестов
│
├── sheet.cpp/.h              — хранение таблицы и управление ячейками
│   ├── создание и удаление ячеек
│   ├── печать таблицы
│   └── вычисление размеров
│
├── cell.cpp/.h               — реализация ячеек
│   ├── Empty / Text / Formula Impl
│   ├── кеширование
│   ├── обработка зависимостей
│   └── проверка циклов
│
├── formula.cpp/.h            — работа с формулами
│   ├── ParseFormula
│   ├── обработка ошибок
│   └── получение списка ссылок
│
├── FormulaAST.cpp/.h         — AST-дерево
│   ├── узлы бинарных и унарных операций
│   ├── узел числа
│   ├── узел ячейки
│   └── восстановление выражения
│
├── Formula.g4                — грамматика формул (ANTLR4)
│
├── common.h                  — Position, Size, ошибки, интерфейсы
│
└── test_runner               — фреймворк для тестирования
```
Все модули изолированы и общаются через интерфейсы:
`SheetInterface`, `CellInterface`, `FormulaInterface`.

# Ключевые технические детали

## Собственная архитектура ячеек

Используется паттерн *стратегии*:
каждая ячейка хранит указатель на реализацию (Impl):

* EmptyImpl — пустая
* TextImpl — текстовая
* FormulaImpl — формула с AST и кешем

Это позволяет:

* расширять функциональность без изменения интерфейсов
* разделить ответственность разных типов ячеек
* избавиться от необходимости использования множественного if (is_formula)

## Кеширование через mutable std::optional

Внутри `FormulaImpl` хранится:

```cpp
mutable std::optional<Value> cache_;
```

`mutable` позволяет вычислять кеш внутри `const GetValue()` — метод логически константен, но может сохранить оптимизацию.

## Обход зависимостей через BFS

Оба важнейших процесса — инвалидация кеша и поиск циклов — реализованы через BFS, что обеспечивает:
* отсутствие переполнения стека
* стабильное поведение на длинных цепочках
* правильный порядок обхода зависимостей

## ANTLR4

Проект использует полноценную грамматику:

* генерация лексера/парсера
* собственный `Listener` для сборки AST
* корректная диагностика ошибок парсинга
* устойчивость к неверному вводу

## std::variant для значений

`CellInterface::Value` — это:

```cpp
std::variant<std::string, double, FormulaError>
```

Позволяет:

* сохранять строгую типизацию
* избегать ручных преобразований
* выдавать ошибки формул как отдельный тип

# Использование

Таблица полностью управляется через API:

```cpp
auto sheet = CreateSheet();
sheet->SetCell("A1"_pos, "10");
sheet->SetCell("A2"_pos, "=A1*2");

std::cout << sheet->GetCell("A2"_pos)->GetValue();   // → 20
```
---

# Пример работы

### Формулы

```
=1+2*3          // 7
=(2+3)*4        // 20
=A1+B2          // сумма значений ячеек
'=not_formula   // выводит "=not_formula"
```

### Ошибки

```
=1/0            // #ARITHM!
=XYZ10000       // #REF!
="abc"+5        // #VALUE!
```

### Печать

```cpp
sheet->PrintTexts()
sheet->PrintValues()
```
